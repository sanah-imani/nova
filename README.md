# Nova

A tiny hobby kernel built in QEMU focusing on:

- Framebuffer graphics
- Software rendering
- Mouse-driven window system
- Minimal composited desktop

Goal: boot into a graphical environment with movable windows.

## Milestones

- [ ] Boot in QEMU
- [ ] Framebuffer initialized
- [ ] Pixel rendering
- [ ] Text rendering
- [ ] Mouse cursor
- [ ] Draggable windows
- [ ] Basic compositor
